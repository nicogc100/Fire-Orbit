# Atlas del fuego

En Windows, abre **Abrir Tierra.cmd**. Necesitas Python 3 y un navegador compatible con WebGL 2.

Si prefieres usar la terminal, ejecuta este comando desde esta carpeta.

```powershell
python iniciar.py --tierra
```

La aplicación se abre en [127.0.0.1:8000/tierra/](http://127.0.0.1:8000/tierra/). Mantén abierta la ventana del servidor mientras la usas.

La Tierra, las nubes y la cartografía se sirven desde `tierra/`. Los datos guardados de Chile y Portugal y su procedencia están en `data/`.
